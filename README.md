# cyclone-previews

Превью прототипов интерфейсов для быстрого просмотра с телефона. Раздаётся через GitHub Pages: [kkoder-cyclone.github.io/cyclone-previews](https://kkoder-cyclone.github.io/cyclone-previews/).

## Превью

| Прототип | Ссылка |
|---|---|
| Панель метрик | [dashboard/](https://kkoder-cyclone.github.io/cyclone-previews/dashboard/) |
| Редизайн | [redesign/](https://kkoder-cyclone.github.io/cyclone-previews/redesign/) |

## Как добавить новое превью

1. Создайте папку и положите в неё статические файлы (HTML/CSS/JS).
2. Добавьте ссылку на превью в `index.html`.
3. Оформите PR в `main` — после мержа страница опубликуется автоматически.

## Правила

- Только синтетические тестовые данные.
- Никаких настоящих отчётов, секретов, почт и ID таблиц.
- Репозиторий публичный — не коммитим ничего чувствительного.
