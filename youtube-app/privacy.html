Политика конфиденциальности приложения Cyclone Kai

Дата вступления в силу: 17.10.2026. Адрес страницы: https://kkoder-cyclone.github.io/cyclone-previews/youtube-app/privacy.

1. Главное

  1. Приложение Cyclone Kai загружает видео только на 2 собственных YouTube-канала владельца.
  2. Каналы: «Код под капюшоном» и «Планёрка в манеже».
  3. Приложение просит у Google только права для загрузки видео и работы с видео своих каналов.
  4. Приложение не собирает данные других людей.
  5. Приложение не показывает рекламу. Рекламы третьих лиц нет.
  6. Приложение не продаёт данные и не передаёт их для рекламы.

2. Владелец и контакты

  1. Владелец приложения: Сучков Кирилл Владимирович, самозанятый (плательщик налога на профессиональный доход), Россия.
  2. Почта для вопросов о данных: kcodex@cyclonev2.com.
  3. Сайт приложения: https://kkoder-cyclone.github.io/cyclone-previews/youtube-app/.
  4. Дальше в тексте владелец — «мы».

3. Что делает приложение

  1. Приложение работает с YouTube API Services (программные службы YouTube от Google).
  2. Мы загружаем видео на свои каналы через это приложение.
  3. Каждую загрузку сначала одобряет владелец.
  4. Приложение передаёт в YouTube эти данные:
  5. файл видео;
  6. обложку;
  7. название;
  8. описание с таймкодами (отметками времени);
  9. теги;
  10. категорию;
  11. язык;
  12. статус доступа: закрытое, по ссылке или открытое (по умолчанию закрытое);
  13. время публикации, если его задал владелец;
  14. отметку о синтетическом содержании (созданном искусственным интеллектом);
  15. отметку «для детей» (да или нет);
  16. плейлист, если владелец его выбрал.
  17. Приложение не читает комментарии, подписчиков и статистику каналов.
  18. Приложение не удаляет видео.
  19. Приложением пользуется только владелец каналов. Другие люди не входят в приложение.

4. Права Google

  1. Приложение просит право youtube. Приложение использует его только для загрузки своих видео, обложки, времени публикации и добавления в свой плейлист. Удаление, правку видео и комментарии приложение не делает.
  2. Владелец может добавить право youtube. Это право разрешает добавить видео в плейлист и изменить время публикации.
  3. Приложение использует право youtube только для работы с видео своих каналов.
  4. Других прав приложение не просит.

5. Какие данные получает и хранит приложение

  1. Мы храним 3 значения ключа доступа Google:
  2. идентификатор клиента;
  3. секрет клиента;
  4. токен обновления (электронный ключ, который выдаёт Google).
  5. Мы храним эти 3 значения только в зашифрованном виде.
  6. Если у каналов разные аккаунты Google, мы храним 2 токена обновления.
  7. Токен доступа мы не храним. Программа держит его только в памяти около 1 часа.
  8. Мы получаем ответ YouTube после загрузки: номер видео, статус доступа и время публикации.
  9. Мы храним номер и статус видео не дольше 30 дней.
  10. Приложение не получает пароль от аккаунта Google. Владелец входит в Google на странице Google.
  11. Приложение не получает почту, имя, контакты и платёжные данные.
  12. Приложение не ставит файлы cookie (небольшие файлы в браузере) и не следит за действиями пользователя.

6. Зачем приложение использует данные

  1. Ключ доступа нужен только для загрузки видео и работы с видео своих каналов.
  2. Номер видео нужен, чтобы владелец нашёл видео в Студии YouTube.
  3. Другой цели нет.

7. Как мы храним данные

  1. Мы храним ключ доступа на сервере в зашифрованном файле.
  2. Шифрование: алгоритм Fernet (симметричное шифрование AES-128 с проверкой целостности).
  3. Ключ шифрования лежит в отдельном файле.
  4. Оба файла доступны только служебной учётной записи сервера. Права файлов — 600, права папки — 700.
  5. Программа загрузки не печатает ключ доступа и не пишет его в журналы.
  6. Мы не храним ключ доступа в открытом виде, в чатах и в хранилищах кода.
  7. Программа передаёт данные в Google только по защищённому протоколу HTTPS.

8. Кому мы передаём данные

  1. Мы передаём видео и его данные только в YouTube. Так работает загрузка.
  2. Мы не передаём данные третьим лицам.
  3. Мы не продаём данные.
  4. Мы раскрываем данные, только если этого требует закон.
  5. Мы не показываем рекламу и не разрешаем третьим лицам показывать рекламу или содержание в приложении.

9. Ограниченное использование (Limited Use)

Ограниченное использование — обязательное правило Google для данных из его программных служб. 1. Мы используем и передаём данные из программных служб Google по правилу Google API Services User Data Policy (политика Google о данных пользователей). 2. Мы соблюдаем требования ограниченного использования из этого правила. 3. Текст правила: https://developers.google.com/terms/api-services-user-data-policy. 4. Мы используем данные только для загрузки видео и работы с видео своих каналов. 5. Мы не передаём данные людям и компаниям, кроме случаев из раздела 8. 6. Мы не используем данные для рекламы, в том числе для рекламы по интересам. 7. Мы не продаём данные посредникам и брокерам данных. 8. Мы не используем данные для оценки платёжеспособности и для выдачи кредитов. 9. Люди не читают данные. Исключения: согласие пользователя, защита от злоупотреблений, требование закона. 10. Мы не используем данные для обучения моделей искусственного интеллекта.

10. YouTube и Google

  1. Приложение использует YouTube API Services.
  2. Пользователь приложения принимает Условия использования YouTube: https://www.youtube.com/t/terms.
  3. Google обрабатывает данные по своей Политике конфиденциальности: http://www.google.com/policies/privacy (тот же текст: https://policies.google.com/privacy).
  4. Условия YouTube API Services: https://developers.google.com/youtube/terms/api-services-terms-of-service.

11. Срок хранения, отзыв доступа и удаление

  1. Мы храним ключ доступа, пока владелец не отзовёт доступ.
  2. Чтобы отозвать доступ, откройте страницу настроек безопасности Google: https://security.google.com/settings/security/permissions (тот же адрес: https://myaccount.google.com/permissions). Удалите доступ приложения Cyclone Kai.
  3. Когда мы удаляем данные, мы сначала отзываем токен у Google программно.
  4. После отзыва доступа мы удаляем зашифрованный файл и ключ шифрования в течение 7 дней.
  5. Запрос на удаление данных присылайте на kcodex@cyclonev2.com. Мы удаляем данные в течение 7 дней после запроса.
  6. Видео на каналах остаются. Владелец удаляет их сам в Студии YouTube.

12. Права пользователя

  1. Пользователь может узнать, какие данные хранит приложение.
  2. Пользователь может потребовать удалить данные.
  3. Пользователь может отозвать доступ в любой момент по разделу 11.
  4. Мы обрабатываем персональные данные по закону России № 152-ФЗ «О персональных данных».

13. Дети

  1. Пользователь приложения — только владелец каналов, взрослый человек.
  2. Приложение не собирает данные детей и данные зрителей.

14. Изменения политики

  1. Мы публикуем новую версию на этой странице.
  2. Мы меняем дату вступления в силу в начале страницы.
  3. Если приложение попросит право Google, которого нет в разделе 4, мы сначала изменим эту политику.
