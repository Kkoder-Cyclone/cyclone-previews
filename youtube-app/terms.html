Условия использования приложения Cyclone Kai

Дата вступления в силу: 17.10.2026. Адрес страницы: https://kkoder-cyclone.github.io/cyclone-previews/youtube-app/terms.

1. Главное

  1. Приложение Cyclone Kai загружает видео на 2 YouTube-канала владельца.
  2. Каналы: «Код под капюшоном» и «Планёрка в манеже».
  3. Приложение служит только владельцу. Другим людям приложение не продаётся и не выдаётся.
  4. Пользователь приложения принимает эти условия и Условия использования YouTube.

2. Стороны

  1. Владелец приложения: Сучков Кирилл Владимирович, самозанятый, Россия. Дальше — «владелец».
  2. Пользователь: человек, который входит в приложение через аккаунт Google.
  3. Сейчас пользователь только один — владелец каналов.
  4. Почта: kcodex@cyclonev2.com. Сайт приложения: https://kkoder-cyclone.github.io/cyclone-previews/youtube-app/.

3. Что делает приложение

  1. Приложение работает с YouTube API Services (программные службы YouTube от Google).
  2. Приложение загружает файл видео и обложку.
  3. Вместе с видео приложение передаёт название, описание с таймкодами (отметками времени), теги, категорию и язык.
  4. Приложение передаёт статус доступа: закрытое, по ссылке или открытое. По умолчанию статус закрытый.
  5. Приложение передаёт время публикации, если его задал владелец.
  6. Приложение передаёт отметку о синтетическом содержании (созданном искусственным интеллектом) и отметку «для детей» (да или нет).
  7. Приложение добавляет видео в плейлист, если владелец его выбрал.
  8. Приложение просит у Google право youtube. Оно использует право только для загрузки своих видео, обложки, времени публикации и своих плейлистов.
  9. Приложение не читает комментарии, подписчиков и статистику. Приложение не удаляет видео.
  10. Приложение не показывает рекламу. Рекламы третьих лиц нет.

4. YouTube и Google

  1. Пользователь принимает Условия использования YouTube: https://www.youtube.com/t/terms.
  2. Google обрабатывает данные по своей Политике конфиденциальности: http://www.google.com/policies/privacy (тот же текст: https://policies.google.com/privacy).
  3. Приложение соблюдает Правила YouTube для разработчиков: https://developers.google.com/youtube/terms/developer-policies.
  4. Условия YouTube API Services: https://developers.google.com/youtube/terms/api-services-terms-of-service.
  5. Приложение не принадлежит Google и YouTube. Google и YouTube не одобряли приложение.

5. Обязанности пользователя

  1. Загружайте только видео, на которые у вас есть права.
  2. Соблюдайте правила сообщества YouTube и закон.
  3. Ставьте отметку о синтетическом содержании, если YouTube этого требует.
  4. Ставьте отметку «для детей», если видео сделано для детей.
  5. Не используйте приложение для спама, обмана и нарушения чужих прав.
  6. Не пытайтесь обойти ограничения YouTube и квоты Google.

6. Данные

  1. Владелец обрабатывает данные по Политике конфиденциальности приложения: https://kkoder-cyclone.github.io/cyclone-previews/youtube-app/privacy.
  2. Приложение хранит идентификатор клиента, секрет клиента и токен обновления в зашифрованном файле на сервере.
  3. Токен доступа приложение не хранит. Программа держит его только в памяти.
  4. Номер и статус видео приложение хранит не дольше 30 дней.
  5. Владелец использует данные Google по правилу Google API Services User Data Policy (политика Google о данных пользователей).
  6. Владелец соблюдает требования Limited Use (ограниченное использование) из этого правила.

7. Отзыв доступа и прекращение работы

  1. Пользователь отзывает доступ на странице https://security.google.com/settings/security/permissions (тот же адрес: https://myaccount.google.com/permissions).
  2. После отзыва приложение больше не загружает видео.
  3. При удалении данных владелец сначала отзывает токен у Google программно.
  4. Владелец удаляет ключ доступа в течение 7 дней после отзыва доступа или после запроса на удаление.
  5. Владелец может остановить приложение в любой момент.
  6. Видео на каналах остаются после отзыва доступа.

8. Ответственность

  1. Владелец предоставляет приложение «как есть».
  2. Владелец не обещает, что приложение работает без перерывов и ошибок.
  3. Владелец не отвечает за решения YouTube: ограничения, блокировки, удаление видео.
  4. Владелец не отвечает за содержание видео, которое загружает пользователь.
  5. Ограничение ответственности действует в пределах, которые разрешает закон.
